# Currículo e Preparação - Patrick Serrano (Clojure & ClojureScript)

Este repositório contém o código-fonte LaTeX do currículo, cartas de apresentação e notas de preparação para entrevistas.

## Arquivos Principais

- `Patrick_Serrano_Clojure_Senior_PTBR_2026.tex`: Currículo sênior focado em Clojure/ClojureScript.
- `Patrick_Serrano_CartaApresentacao_Buzzlabs.tex`: Carta de apresentação estratégica para a Buzzlabs.
- `Preparacao_Entrevista_Buzzlabs.md`: Guia de narrativa, respostas técnicas e estratégias para a entrevista.

## Pré-requisitos

Para compilar os arquivos `.tex`, você precisará de uma distribuição LaTeX instalada (ex: TeX Live, MiKTeX ou MacTeX).

## Como Compilar (Linha de Comando)

Para o currículo:
```bash
pdflatex Patrick_Serrano_Clojure_Senior_PTBR_2026.tex
```

Para a carta de apresentação:
```bash
pdflatex Patrick_Serrano_CartaApresentacao_Buzzlabs.tex
```

## Estrutura do Projeto

- `.tex`: Fontes dos documentos.
- `.pdf`: Versões compiladas prontas para envio.
- `Preparacao_*.md`: Notas estratégicas para empresas específicas.
